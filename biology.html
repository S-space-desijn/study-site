七年级上册细胞 · 生物体结构层次 · 绿色植物

  • 生物的特征：应激性、生长、繁殖、新陈代谢（最基本特征：生活需要营养、能进行呼吸、排出废物）、除病毒外都由细胞构成、都有遗传变异。
  • 生物圈：地球上所有生物及其生活环境；范围包括大气圈下层、整个水圈、岩石圈上层；为生物提供营养物质、阳光、空气、水、适宜温度和生存空间。
  • 生物多样性：物种多样性、遗传（基因）多样性、生态系统多样性；遗传多样性是实质和基础。
  • 生物与环境：环境影响生物（非生物因素：阳光、水、温度、空气；生物因素：捕食、竞争、合作、寄生）；生物适应环境（保护色、警戒色、拟态），也影响和改变环境（蚯蚓松土、大树底下好乘凉）。
探究实验一般过程：发现并提出问题 → 收集信息作出假设 → 设计并完成实验（设置对照、控制单一变量、重复实验取平均值）→ 分析现象得出结论 → 表达交流。

显微镜使用

  • 步骤：取镜安放 → 对光（低倍镜、大光圈、看到明亮视野）→ 放置玻片 → 观察（降镜筒时眼睛注视物镜防压碎；左眼注视目镜，右眼睁开便于画图）→ 收放。
  • 放大倍数 = 目镜倍数 × 物镜倍数；倍数越大，看到细胞越大、数目越少、视野越暗。
  • 像为倒像（上下颠倒、左右相反）：物像偏哪就向哪移动玻片；污点位置：移动目镜/玻片判断。
  • 光线弱时用大光圈、凹面镜；光线强时用小光圈、平面镜；低倍换高倍后不能动粗准焦螺旋。

植物体层次：细胞 → 组织（保护、营养、输导、分生组织）→ 器官（营养器官：根、茎、叶；生殖器官：花、果实、种子）→ 植物体。
动物体层次：细胞 → 组织（上皮、肌肉、结缔、神经组织）→ 器官 → 系统（八大系统）→ 动物体（人体）。
  • 分生组织细胞小、壁薄、核大、质浓，有很强分裂能力；输导组织中导管运输水和无机盐（自下而上），筛管运输有机物（自上而下）。
  • 人体四大组织：上皮组织（保护分泌，皮肤表皮、腺体）、结缔组织（支持连接营养保护，血液、骨、软骨、肌腱）、肌肉组织（收缩舒张，平滑肌/骨骼肌/心肌）、神经组织（接受刺激产生传导兴奋，脑脊髓神经）。
叶片是器官，叶肉是营养组织；血液是组织（结缔组织），心脏是器官，植物的一片叶是器官。

光合作用

概念：绿色植物通过叶绿体，利用光能，把二氧化碳和水合成储存能量的有机物（主要是淀粉），并释放氧气。
表达式：二氧化碳 + 水 ——(光能，叶绿体)→ 有机物（储存能量）+ 氧气。
意义：制造有机物（食物来源）、储存能量（能量来源）、释放氧气（维持碳—氧平衡）。
  • “绿叶在光下制造淀粉”实验：暗处理（耗尽原有淀粉）→ 部分遮光（对照，变量光）→ 光照 → 酒精隔水加热脱色 → 清水漂洗 → 滴碘液 → 见光部分变蓝（产生淀粉），遮光部分不变蓝。
  • 探究光合作用需要二氧化碳（氢氧化钠吸收 CO₂）、产生氧气（金鱼藻收集气体使带火星木条复燃）、场所是叶绿体（银边天竺葵）。

呼吸作用

概念：细胞内有机物在氧参与下被分解成二氧化碳和水，同时释放能量。
表达式：有机物（储存能量）+ 氧气 → 二氧化碳 + 水 + 能量；主要场所：线粒体；所有活细胞时刻进行。
意义：为生命活动（细胞分裂、吸收无机盐、运输有机物等）提供动力。
光合 vs 呼吸：光合只在有光时、含叶绿体的细胞进行，合成有机物、储存能量；呼吸昼夜都进行、所有活细胞都进行，分解有机物、释放能量。新疆瓜果甜、大棚增产：增大昼夜温差，白天促进光合、夜晚低温抑制呼吸。

吸收作用

  • 根吸水主要部位：根尖成熟区（大量根毛增大面积）；根吸水动力是蒸腾作用；原理：细胞液浓度 > 周围溶液浓度时吸水，反之失水（“烧苗”）。
  • 植物需要量最多的无机盐：氮（叶茂）、磷（开花结果）、钾（茎秆健壮、促淀粉运输）；缺氮叶片发黄、缺磷暗绿带紫、缺钾叶缘焦枯。

运输作用

木质部中导管（死细胞）自下而上运输水和无机盐；韧皮部中筛管（活细胞）自上而下运输有机物。“树怕伤皮不怕空心”——伤皮切断筛管。

蒸腾作用

  • 主要通过叶片气孔（由两个半月形保卫细胞围成，下表皮多于上表皮）散失水分；意义：降低叶面温度、产生蒸腾拉力促进水和无机盐运输、提高大气湿度增加降水。
  • 移栽植物：带土坨（保护根毛）、剪去部分枝叶、阴天或傍晚移栽（降低蒸腾）。

种子结构与萌发

  • 大豆种子（双子叶）：种皮 + 胚（胚芽、胚轴、胚根、两片子叶）；营养储存在子叶。
  • 玉米种子（单子叶）：果皮和种皮 + 胚 + 胚乳；营养储存在胚乳，子叶 1 片转运营养；滴碘液胚乳变蓝。
  • 胚是新植物的幼体，是种子主要部分。
  • 萌发自身条件：胚完整且活、度过休眠期、有供胚发育的营养物质；外界条件：适量的水分、适宜的温度、充足的空气（光不是必要条件）。
  • 萌发过程：胚根先突破种皮发育成根 → 胚轴伸长 → 胚芽发育成茎和叶。

开花结果

  • 花的主要结构是雄蕊（花药+花丝）和雌蕊（柱头+花柱+子房）；花药产生花粉（内有精子），子房内有胚珠（内有卵细胞）。
  • 过程：开花 → 传粉（自花/异花，媒介主要是昆虫和风力）→ 受精（精子+卵细胞结合）→ 结果。
  • 受精后：子房发育成果实，子房壁发育成果皮，胚珠发育成种子，珠被发育成种皮，受精卵发育成胚，受精极核发育成胚乳。
葵花籽、玉米粒是果实（果皮种皮紧贴）；西瓜籽、花生仁是种子；“麻屋子（果皮）、红帐子（种皮）、白胖子（胚）”。

消化系统

  • 组成：消化道（口→咽→食道→胃→小肠→大肠→肛门）和消化腺（唾液腺、肝脏、胰腺、胃腺、肠腺）。
  • 肝脏是最大的消化腺，分泌胆汁（不含消化酶，乳化脂肪为脂肪微粒，物理性消化）；胰腺分泌胰液。
  • 消化过程：淀粉在口腔开始消化（唾液淀粉酶→麦芽糖，在小肠最终变葡萄糖）；蛋白质在胃开始（胃蛋白酶，最终变氨基酸）；脂肪只在小肠消化（胆汁+胰液肠液→甘油和脂肪酸）。
  • 小肠是消化和吸收的主要器官：长（5～6 m）、有皱襞和小肠绒毛增大面积、绒毛壁和毛细血管壁仅一层上皮细胞、含肠液胰液胆汁多种消化液。
合理膳食：平衡膳食宝塔，早中晚能量比约 3:4:3；关注食品安全（QS/SC 标志、保质期、绿色食品）。

红细胞数量最多，成熟无细胞核，含血红蛋白（含铁、易与氧结合）运输氧和部分二氧化碳；少→贫血，多吃含铁蛋白质食物

血管与心脏

  • 动脉：离心送血，管壁厚弹性大、血流快；静脉：回心，壁薄弹性小、有静脉瓣；毛细血管：内径最小（红细胞单行通过）、壁仅一层上皮细胞、血流最慢，适于物质交换。
  • 心脏四腔：上房下室（左心房、左心室、右心房、右心室）；左心室壁最厚（体循环动力）；房室瓣、动脉瓣保证血液按一定方向流动（心房→心室→动脉，不倒流）。
  • 相连血管：左心室—主动脉；右心室—肺动脉；左心房—肺静脉；右心房—上下腔静脉。心室连动脉、心房连静脉。

血液循环

体循环：左心室 → 主动脉 → 全身毛细血管网（动脉血变静脉血）→ 上下腔静脉 → 右心房。
肺循环：右心室 → 肺动脉 → 肺部毛细血管网（静脉血变动脉血）→ 肺静脉 → 左心房。
两循环同时进行、在心脏处连通成一条完整路线。
  • 动脉血含氧多、颜色鲜红；静脉血含氧少、颜色暗红；不是按血管名称区分（肺动脉流静脉血，肺静脉流动脉血）。
  • 食物中能量通过呼吸作用释放；热价：脂肪 > 蛋白质 > 糖类。
  • 呼吸系统组成：呼吸道（鼻、咽、喉、气管、支气管）和肺（气体交换主要场所）。
  • 呼吸道功能：气体通道，对吸入气体进行处理——鼻毛过滤、黏膜分泌黏液清洁湿润、毛细血管温暖空气；咽是气体和食物共同通道（会厌软骨在吞咽时盖住喉口）；喉有声带。
  • 肺适于气体交换：肺泡数量多、肺泡壁薄（一层上皮细胞）、外面缠绕丰富毛细血管和弹性纤维。
肋间肌/膈肌胸廓肺肺内气压气体
吸气收缩（膈顶下降）扩大扩张低于外界入肺
呼气舒张（膈顶回升）缩小回缩高于外界出肺
  • 气体交换原理：气体扩散作用（从高浓度到低浓度）；肺泡内 O₂ 进入血液、CO₂ 进入肺泡；组织处血液中 O₂ 进入组织细胞、CO₂ 进入血液。
  • 氧气最终在线粒体中参与呼吸作用；呼出气体中氧气减少、二氧化碳和水增多。

排泄（区别排遗）

  • 排泄三条途径：皮肤排汗（水、无机盐、尿素）；呼吸系统呼气（CO₂、水）；泌尿系统排尿（主要途径）。
  • 泌尿系统：肾脏（形成尿液，基本单位是肾单位：肾小球、肾小囊、肾小管）→ 输尿管 → 膀胱（暂存）→ 尿道。
  • 尿液形成两步：① 肾小球的滤过作用（除血细胞和大分子蛋白质外，血浆中一部分水、无机盐、葡萄糖、尿素滤过形成原尿）；② 肾小管的重吸收作用（原尿中全部葡萄糖、大部分水、部分无机盐被重吸收）。
  • 尿液成分：水、无机盐、尿素；原尿与血浆比少了大分子蛋白质；尿液与原尿比不含葡萄糖。血尿/蛋白尿→肾小球病变；糖尿→肾小管病变或胰岛素不足。

神经调节

  • 神经系统：中枢神经系统（脑、脊髓）和周围神经系统（脑神经、脊神经）；结构功能基本单位是神经元（细胞体+突起：树突接受信息、轴突传出信息）。
  • 反射是神经调节的基本方式；结构基础是反射弧：感受器 → 传入神经（有神经节）→ 神经中枢 → 传出神经 → 效应器。
  • 非条件反射（生来就有、由大脑皮层以下中枢完成）：缩手反射、眨眼反射、膝跳反射、婴儿吮吸；条件反射（后天形成、大脑皮层参与）：望梅止渴、谈虎色变。与语言文字有关的反射是人类特有。
  • 眼：光线 → 角膜 → 瞳孔 → 晶状体（折射，通过睫状体调节曲度）→ 玻璃体 → 视网膜（成像，有感光细胞，产生神经冲动）→ 视神经 → 大脑皮层视觉中枢（形成视觉）。近视：晶状体曲度过大或眼球前后径过长，物像落在视网膜前方，戴凹透镜。
  • 耳：外耳（耳廓、外耳道）、中耳（鼓膜、听小骨、鼓室）、内耳（半规管、前庭、耳蜗有听觉感受器）；听觉在大脑皮层形成；咽鼓管连通咽和鼓室，维持鼓膜两侧气压平衡。

激素调节

激素腺体作用异常症
生长激素垂体促进生长发育幼年不足侏儒症；过多巨人症；成年过多肢端肥大症
甲状腺激素甲状腺促进代谢和生长发育，提高神经系统兴奋性幼年不足呆小症；成年不足黏液性水肿；过多甲亢；缺碘地方性甲状腺肿
胰岛素胰岛（胰腺内）调节糖代谢，降低血糖浓度不足→糖尿病（注射胰岛素治疗，不能口服，本质是蛋白质）

人体生命活动主要受神经系统调节，同时也受激素调节，二者相互协调。

  • 健康：身体上、心理上和社会适应方面的良好状态（不仅是没病）；养成生活规律、合理膳食、合理用药（处方药 R、非处方药 OTC）、拒绝吸烟酗酒吸毒。
  • 传染病特点：传染性、流行性；三个基本环节：传染源（病人、携带者、患病动物）、传播途径（空气飞沫、饮食、血液、接触、生物媒介）、易感人群。
  • 预防措施：控制传染源（隔离治疗、焚烧深埋患病动物）、切断传播途径（消毒、讲卫生、灭蚊蝇）、保护易感人群（锻炼、预防接种）。
  • 免疫三道防线：① 皮肤和黏膜（非特异性）；② 体液中杀菌物质（溶菌酶）和吞噬细胞（非特异性，生来就有、对多种病原体起作用）；③ 免疫器官和免疫细胞产生抗体（特异性免疫，后天形成、只针对特定抗原）。
  • 抗原（引起产生抗体的物质，如病原体、疫苗、移植器官）；抗体是淋巴细胞产生的特殊蛋白质；计划免疫：接种疫苗（属抗原）使人体产生相应抗体和记忆细胞，属于特异性免疫。

八年级上册动物运动与行为 · 动物资源 · 微生物

  • 动物运动方式：水中游泳（鳍、蹼）、陆地爬行/行走/奔跑/跳跃、空中飞行（翼、翅）。
  • 运动系统组成：骨、骨连结、骨骼肌三部分（骨与骨连结构成骨骼）。
  • 关节结构：关节面（关节头、关节窝，表面有关节软骨——减少摩擦缓冲震动）、关节囊（分泌滑液、连接牢固）、关节腔（内有滑液）；特点：既牢固（关节囊、韧带）又灵活（关节软骨、滑液）。脱臼：关节头从关节窝滑脱。
  • 骨骼肌：由肌腹（中间、收缩）和肌腱（两端、附着在不同骨上）组成；一块骨骼肌两端肌腱绕过关节连在不同的骨上。
运动产生：骨骼肌受神经传来的刺激收缩，牵动骨绕关节活动。屈肘：肱二头肌收缩，肱三头肌舒张；伸肘：肱三头肌收缩，肱二头肌舒张；提重物时都收缩，自然下垂时都舒张。运动需要神经系统调节、消化系统/呼吸系统/循环系统配合提供能量。
先天性行为（本能行为）后天学习行为
获得生来就有，由体内遗传物质决定在遗传因素基础上，由生活经验和学习获得
特点同种动物基本相同，相对稳定个体差异大、易变化、越高等动物学习能力越强

  • 按功能类型：取食行为、领域行为、攻击行为（同种之间、很少致死）、防御行为（保护色、警戒色、拟态、假死）、繁殖行为、节律行为（昼夜、季节、潮汐节律）、社群行为（蜜蜂、蚂蚁、狒狒：群体内有组织、分工、等级，靠动作、声音、气味——如性外激素——传递信息）。
  • 动物在生物圈中作用：促进物质循环；帮助植物传粉、传播种子；维持生态平衡；仿生应用（雷达—蝙蝠回声定位、冷光灯—萤火虫、薄壳建筑—龟壳）。
  • 我国珍稀动物：大熊猫、金丝猴、白鳍豚、朱鹮、扬子鳄（中生代动物“活化石”）；生物多样性面临威胁主因：栖息地破坏、掠夺式开发、环境污染、外来物种入侵；保护措施：就地保护（建立自然保护区，最有效）、易地保护（动物园/繁育中心）、法制教育管理。

八年级下册生殖发育 · 遗传变异 · 进化 · 多样性 · 生态系统

  • 人的生殖：男性主要器官睾丸（产生精子、分泌雄性激素）；女性主要器官卵巢（产生卵细胞、分泌雌性激素）；受精场所输卵管；胚胎发育场所子宫；胎儿通过胎盘和脐带从母体获得营养和氧气、排出废物（胎盘进行物质交换）；怀孕约 40 周分娩。
  • 青春期特点：身高突增（显著特征）、神经系统心肺功能增强、性发育和性成熟（突出特征，出现第二性征、男孩遗精、女孩月经）。
类群受精/发育
昆虫体内受精，卵生。完全变态：卵→幼虫→蛹→成虫（家蚕、蜜蜂、蝴蝶、蚊蝇）；不完全变态：卵→若虫→成虫（蝗虫、蟋蟀、螳螂、蝉）
两栖动物体外受精（水中），卵生；变态发育：受精卵→蝌蚪（像鱼、用鳃呼吸）→幼蛙→成蛙（用肺呼吸、皮肤辅助）；生殖发育离不开水
鸟类体内受精，卵生；鸟卵结构：卵壳（保护、透气）、卵白（营养和水）、卵黄（主要营养）、胚盘（含细胞核，发育成雏鸟）、气室（供氧）、系带（固定）
  • 植物生殖：有性生殖（经过两性生殖细胞结合，如种子繁殖，后代具有更大变异性）；无性生殖（不经过两性生殖细胞结合，由母体直接产生新个体，保持母本优良性状、繁殖快）——扦插、嫁接（接穗与砧木的形成层紧密结合）、压条、组织培养、分株。
  • 遗传：亲子间相似性；变异：亲子间及子代个体间差异。生物的遗传和变异是通过生殖和发育实现的。
  • 性状：生物体形态结构、生理特性和行为方式；相对性状：同种生物同一性状的不同表现形式（有耳垂/无耳垂）。
  • 细胞核中有染色体（由 DNA 和蛋白质组成），DNA 是主要遗传物质，呈双螺旋结构；基因是 DNA 上有遗传效应的片段，控制生物性状；染色体在体细胞中成对存在，基因也成对。
  • 人的体细胞有 23 对（46 条）染色体；生殖细胞（精子、卵细胞）中 23 条（成单存在）；受精卵中 23 对。
生殖过程中染色体变化：体细胞（2n）→ 生殖细胞（n，减数分裂）→ 受精后受精卵（2n）。
性别决定：男性 XY（产生含 X 或 Y 的两种精子，比例 1:1），女性 XX（只产生含 X 的卵细胞）；生男生女取决于精子类型，机会各 50%。
  • 基因传递：亲代基因经生殖细胞传给子代；显性基因（A）控制显性性状，隐性基因（a）；AA、Aa 表现显性性状，aa 表现隐性性状；近亲结婚后代患隐性遗传病概率增大（我国婚姻法规定直系血亲和三代以内旁系血亲禁止结婚）。
  • 变异类型：可遗传变异（遗传物质改变，如基因突变、基因重组、染色体变异）与不可遗传变异（仅环境引起，遗传物质未变，如晒黑）；应用：人工选择育种、杂交育种（袁隆平杂交水稻）、诱变育种、转基因技术（超级鼠、抗虫棉）。
一对相对性状遗传分析：双亲均为显性（如 Aa×Aa），后代基因型 AA:Aa:aa=1:2:1，显性:隐性=3:1；“无中生有”新出现的性状为隐性性状。
  • 生命起源的化学进化：原始大气（甲烷、氨、水蒸气、氢等，无氧气）在高温、紫外线、雷电作用下形成简单有机物 → 原始海洋（“生命摇篮”）中形成复杂有机物和原始生命；米勒实验模拟证明无机小分子可生成有机小分子。
  • 生物进化证据：化石是最直接、最重要的证据（越古老地层中化石生物越简单低等）；还有比较解剖学（同源器官）、分子生物学（细胞色素 c）等证据。
  • 进化历程：植物：藻类 → 苔藓 → 蕨类 → 种子植物（裸子植物→被子植物）；动物：无脊椎动物 → 鱼类 → 两栖类 → 爬行类 → 鸟类和哺乳类。总趋势：由简单到复杂、由低等到高等、由水生到陆生。
自然选择学说（达尔文《物种起源》）：过度繁殖 → 生存斗争 → 遗传变异 → 适者生存、不适者被淘汰。
变异是不定向的（先有变异），自然选择是定向的（环境起选择作用）；保护色、长颈鹿长颈、细菌抗药性都是自然选择的结果。
  • 人类起源：人类和现代类人猿（长臂猿、猩猩、大猩猩、黑猩猩）共同祖先是森林古猿；进化历程：南方古猿 → 能人 → 直立人（北京猿人，用火）→ 智人；人与猿分界的重要标志是直立行走；劳动在进化中起重要作用。
  • 分类等级（从大到小）：界、门、纲、目、科、属、种；种是最基本单位；分类单位越小，包含生物越少、共同特征越多、亲缘关系越近；林奈双名法（属名+种加词，拉丁文）。
  • 五大类群：原核生物界、原生生物界、真菌界、植物界、动物界（也有六界分法）。

动物类群

  • 无脊椎动物：腔肠动物（水螅、海葵、珊瑚虫，有口无肛门）、扁形动物（涡虫、猪肉绦虫）、线形动物（蛔虫，有口有肛门）、环节动物（蚯蚓，身体由许多体节构成，湿润体壁呼吸）、软体动物（河蚌、乌贼，有外套膜，常具贝壳）、节肢动物（最大门，昆虫是最大纲）：身体分部、体表有外骨骼（防止水分散失、保护，但限制生长需蜕皮）、足和触角分节；蝗虫、蜜蜂、虾蟹、蜘蛛。
  • 鱼类：终生水生，体表鳞片，用鳃呼吸，用鳍游泳，心脏一心房一心室，体外受精，卵生。
  • 两栖类：幼体水生用鳃，成体水陆两栖用肺（皮肤辅助），变态发育，体外受精。
  • 爬行类：真正陆生脊椎动物，体表覆盖角质鳞片或甲，用肺呼吸，体内受精、卵生（卵壳坚韧），摆脱水的限制。
  • 鸟类：体表被覆羽毛，前肢变成翼，用肺呼吸并有气囊辅助（双重呼吸），体温恒定，心脏四腔，卵生。
  • 哺乳类：最高等；体表被毛，胎生、哺乳，体温恒定，大脑发达。
  • 生态系统 = 生物部分 + 非生物部分（阳光、空气、水、温度、土壤）；生物部分包括：生产者（绿色植物）、消费者（动物）、分解者（细菌真菌等营腐生生活的微生物），三者相互依存，生产者和分解者是连接生物与非生物环境的两个重要环节。
  • 食物链：生产者与消费者之间吃与被吃的关系（起点必须是生产者，箭头指向捕食者，不写分解者和非生物部分）；如：草 → 兔 → 狐。
  • 食物网：多条食物链交错；生物富集：有毒物质（DDT、重金属）沿食物链积累，营养级别越高浓度越高。
能量流动特点：单向流动、逐级递减（传递效率约 10%～20%），所以食物链一般不超过 4～5 个营养级；能量最终来源是太阳能。
物质循环特点：反复循环（碳循环以 CO₂ 形式在生物与无机环境间循环；光合作用固定、呼吸作用和分解释放、燃烧也释放）。
  • 生态系统具有一定的自动调节能力，使生态系统保持相对稳定（生态平衡）；生物种类越多、营养结构越复杂，调节能力越强、越稳定（森林 > 草原 > 荒漠）；但调节能力有一定限度，超过限度生态系统会遭到破坏。
  • 人口增长与环境：实行计划生育（控制人口数量、提高人口素质）；生态农业实现物质循环利用、能量多级利用（桑基鱼塘、沼气池）。

实验与图解题专题

  • 显微镜与临时装片：擦→滴（植物滴清水、动物滴生理盐水——保持细胞正常形态）→取→展/涂→盖（盖玻片一侧先接触液滴再缓缓放下，防气泡）→染（碘液，一侧滴另一侧吸）。
  • 探究种子萌发条件：对照实验，水分/温度/空气三组对照，每组只一个变量；用多粒种子避免偶然性。
  • 探究唾液对淀粉消化：馒头碎屑（模拟牙齿咀嚼）、搅拌（模拟舌）、37℃ 水浴（接近体温酶活性最强）、加碘液检验（变蓝说明有淀粉）；加唾液组不变蓝。
  • 绿叶在光下制造淀粉：暗处理—遮光—光照—酒精隔水脱色—碘液检验（见光变蓝）。
  • 探究呼吸作用：萌发种子瓶中温度升高（放热）、气体使澄清石灰水变浑浊（产生 CO₂）、使燃烧蜡烛熄灭（消耗 O₂）；煮熟种子为对照。
  • 验证光合产生氧气：金鱼藻在光下产生气泡，收集气体使带火星卫生香/木条复燃。
  • 探究甲状腺激素作用：蝌蚪饲喂实验（加激素组提前发育成小青蛙）；设置正常组对照。
  • 动植物细胞对比图：细胞壁、叶绿体、液泡是植物细胞“三大件”。
  • 叶片横切面：上/下表皮（有气孔，保卫细胞围成）、叶肉（栅栏组织、海绵组织，含叶绿体）、叶脉（导管+筛管）。
  • 消化系统图：识图顺序口→胃→小肠（盘曲最长）；肝脏在右上腹、胃左上腹。
  • 心脏图：“上房下室、左右相反（图上右边为心脏左侧）”；心室壁厚于心房，左心室最厚。
  • 血液循环图：体循环“左室出右房回”，肺循环“右室出左房回”。
  • 肾单位：肾小球（毛细血管球）+肾小囊（套在球外）+肾小管（外绕出球小动脉形成的毛细血管网）。
  • 反射弧：找神经节（传入神经上有膨大部分）确定方向。
  • 关节图：关节头、关节窝、关节软骨、关节囊、关节腔。
  • 花的结构图与发育：子房→果实、胚珠→种子。
